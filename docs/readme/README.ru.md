# AnonPDF

[English](../../README.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md) · [हिन्दी](README.hi.md) · [Português](README.pt-BR.md) · **Русский** · [中文](README.zh-CN.md)

Программа для чтения и правки PDF, которая работает на вашем устройстве и больше нигде.

**Без рекламы. Без аккаунта. Без слежки. Без платной версии. Без доступа к сети.**

AnonPDF появился потому, что все остальные PDF-приложения, кажется, хотят подписку,
облачный аккаунт и возможность заглянуть в ваши документы. Этому ничего из этого не
нужно. Он не может отправить ваши файлы, потому что у него нет разрешения на доступ
к сети. Это не обещание в политике конфиденциальности, а ограничение, которое
обеспечивает сама операционная система.

## Скачать

- **Android:** APK из [последнего релиза](https://github.com/FanFeast/anonpdf/releases/latest). Скоро в Google Play.
- **Linux:** `sudo snap install anonpdf` из [Snap Store](https://snapcraft.io/anonpdf) или переносной архив
  `AnonPDF-…-linux-x86_64.tar.gz` из [последнего релиза](https://github.com/FanFeast/anonpdf/releases/latest):
  распакуйте и дважды щёлкните `AnonPDF.AppImage`. Ничего не устанавливается.
- **Windows:** переносной `AnonPDF-…-windows-x64.zip` из [последнего релиза](https://github.com/FanFeast/anonpdf/releases/latest):
  распакуйте и запустите `AnonPDF.exe`.

Версия для компьютера — тот же движок и тот же редактор в обычном окне, с тем же
правилом: никакого доступа к сети.

## Редактор

Здесь происходит почти всё. Выберите страницы, накопите сколько угодно изменений,
смотрите, как обновляется настоящий результат, и запишите файл один раз в конце.
До сохранения на диск ничего не пишется, а исходный файл никогда не меняется.

|---|---|---|
| ![Редактор](../screenshots/editor.png) | ![Порядок](../screenshots/editor-reorder.png) | ![Скрыто](../screenshots/editor-collapsed.png) |

| Закрыть и переписать | Выделить и нарисовать | Вставить и продолжить |
|---|---|---|
| ![Текст](../screenshots/editor-text.png) | ![Рисунок](../screenshots/editor-draw.png) | ![Объединение](../screenshots/editor-merge.png) |

- **Все инструменты в одном месте**, на четырёх страницах: *Страницы*,
  *Содержимое*, *Весь файл* и *Преобразовать и защитить*. Инструменты для всего
  файла получают документ уже с вашими несохранёнными изменениями.
- **Заполнение PDF-форм**: текстовые поля, флажки, переключатели и списки, с
  предпросмотром при вводе и возможностью закрепить ответы на странице при
  сохранении.
- **Объединение вставляет туда, куда вы скажете.** Страницы другого PDF становятся
  обычными страницами, которые можно поворачивать, переставлять, обрезать и удалять.
- **Правьте содержимое, а не только страницы.** Закройте что-то замазкой и
  напишите поверх свой текст, выделите фрагмент или рисуйте от руки. Замазка
  действительно удаляет закрытое: страница под ней становится изображением, и
  скрытый текст больше нельзя скопировать или найти поиском.
- **Переставляйте перетаскиванием** и **выбирайте несколько страниц касанием**.
- **Отмена и повтор** по всей истории.

Предпросмотр — не приближение: его строит тот же код, что пишет итоговый файл, а
тест проверяет, что они совпадают попиксельно.

## Гарантия и как её проверить

AnonPDF запрашивает ровно **одно** разрешение:

```
android.permission.MANAGE_EXTERNAL_STORAGE
```

Оно позволяет встроенному обзору показывать PDF на устройстве. Оно
**необязательно**: если отказаться, всё работает через системное окно выбора,
которому разрешения не нужны. Android считает его «специальным доступом», поэтому
на обычной странице разрешений приложения его не видно.

На что можно положиться:

- **Нет разрешения `INTERNET`.** Система отклоняет любое подключение. Нет сервера,
  телеметрии, отчётов о сбоях и рекламных сетей. Тесты проверяют, что открыть
  соединение и разрешить имя хоста действительно невозможно.
- **Нет библиотек аналитики и рекламы.** Только AndroidX, Kotlin и PdfBox-Android.
- **`allowBackup=false`**, так что документы не уходят и через облачные копии.
- **Тест ломает сборку**, если появится любое другое разрешение.

Проверьте сами:

```bash
apkanalyzer manifest permissions app-release.apk
```

### Что хранится

| Что | Где | Как удалить |
|---|---|---|
| Имена до 20 недавних файлов | Личное хранилище приложения, без резервных копий | Настройки → Очистить недавние файлы |
| Рабочие копии редактируемого файла | Кеш приложения | Настройки → Удалить временные файлы; также при каждом запуске |
| Три настройки отображения | Личное хранилище приложения | Удалить приложение |

Это полный список. Никаких идентификаторов.

## Возможности

**Чтение:** непрерывная прокрутка, масштабирование двумя пальцами, переход к
странице, поиск по тексту, ночной режим, PDF с паролем.

**Поиск файлов:** встроенный обзор всех PDF на устройстве, по папкам, или
системное окно выбора.

**Правка** (всё за один проход, с предпросмотром): поворот, обрезка, изменение
размера (A3, A4, A5, Letter, Legal, Tabloid), удаление, перестановка, объединение,
заполнение форм, текст, замазка, выделение, рисунок, водяной знак и номера страниц.

**Файлы целиком:** объединить, разделить, извлечь страницы, сжать, PDF в JPG/PNG,
изображения в PDF, извлечь текст, защитить AES-256 или снять пароль, подписать.

**При сохранении:** по желанию удалить скрытые сведения PDF (автор, программа,
даты, метаданные XMP, вложенные файлы, скрипты и имена в комментариях).

**Языки:** английский, немецкий, испанский, французский, хинди, бразильский
португальский, русский и упрощённый китайский — по языку устройства.

## Чего нет, и это намеренно

- **Преобразования в Word, Excel или PowerPoint.** Для хорошего результата нужен
  полноценный офисный движок.
- **Распознавания текста (OCR).** Для него нужна большая модель или сервер.
- **Синхронизации, аккаунтов, ссылок для общего доступа.** Смысл в том, что ничего
  не уходит с устройства.
- **Форм XFA** — этот формат заполняют только приложения Adobe.
- **Криптографических электронных подписей.** «Подписать PDF» ставит изображение
  подписи: это чернила на бумаге, а не сертификат.
